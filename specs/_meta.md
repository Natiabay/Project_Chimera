# Project Chimera: Meta Specification

## Vision
Build a factory for 1000+ autonomous AI influencers with economic agency.

## Core Constraints
1. All external calls MUST use MCP (no direct APIs)
2. Must implement FastRender Swarm (Planner-Worker-Judge)
3. Every agent gets a non-custodial wallet via Coinbase AgentKit
4. Human-in-the-loop for safety via confidence scoring

## Success Metrics
- Response latency: <10 seconds (NFR 3.1)
- Concurrency: 1000+ agents (NFR 3.0)
- Budget control: <$50 daily/agent (FR 5.2)
- AI disclosure: 100% compliance (NFR 2.0)

## OpenClaw Integration Strategy
Phase 1: Internal swarm only (private vertical network)
Phase 2: Broadcast capabilities via MCP resource
Phase 3: Agent-to-agent commerce with reputation oracles
